# Diabetic Prediction App

An interactive, Machine Learning-powered healthcare web dashboard built with **Streamlit**, **Scikit-Learn**, **Pandas**, and **Plotly**. This application enables real-time diabetes risk prediction based on patient health metrics, visualizes exploratory dataset analytics, and provides tailored medical lifestyle recommendations.

---

## Key Features

- **Real-Time Diabetes Risk Prediction**: Input patient health parameters via the sidebar to immediately calculate diabetes risk and exact prediction probability percentage.
- **Interactive Risk Meter & Categorization**:
  - **Low Risk** (< 40% probability)
  - **Moderate Risk** (40% - 69% probability)
  - **High Risk** (≥ 70% probability)
- **Actionable Health Recommendations**: Dynamic health, lifestyle, and dietary advice customized based on the patient's assessed risk level.
- **Exploratory Data Visualizations (Plotly)**:
  - **Diabetic vs. Non-Diabetic Distribution**: Interactive donut chart.
  - **Glucose & BMI Distributions**: Overlay histograms showing feature distributions per outcome.
  - **Multivariate Scatter Plots**: Glucose vs. BMI (sized by Age) and Age vs. Insulin (sized by BMI).
  - **Age Distribution**: Box plot comparative analysis.
  - **Feature Correlation Heatmap**: Matrix visualizing inter-feature relationships.
- **Dataset & Statistical Analytics**: Integrated preview of patient records, overall dataset summary metrics, and key performance indicators (Total Patients, Diabetic, Non-Diabetic, Model Accuracy).

## Clinical Input Parameters

The prediction model evaluates 8 physiological health indicators:

| Parameter | Unit / Scale | Range in App | Description |
| :--- | :--- | :--- | :--- |
| **Pregnancies** | Count | 0 – 20 | Number of times pregnant |
| **Glucose** | mg/dL | 0 – 250 | 2-hour oral glucose tolerance test concentration |
| **Blood Pressure** | mmHg | 0 – 150 | Diastolic blood pressure |
| **Skin Thickness** | mm | 0 – 100 | Triceps skin fold thickness |
| **Insulin** | μU/mL | 0 – 900 | 2-Hour serum insulin level |
| **BMI** | kg/m² | 0.0 – 70.0 | Body Mass Index (weight in kg / (height in m)²) |
| **Diabetes Pedigree Function** | Score | 0.0 – 3.0 | Genetic score based on diabetes history in relatives |
| **Age** | Years | 1 – 120 | Patient age |

## Getting Started

### 1. Prerequisites

Ensure you have Python installed on your system (Python 3.8 or higher recommended). Verify installation:

```bash
python --version
```

### 2. Installation

1. **Clone or download** this repository and navigate to the project directory:

   ```bash
   cd diabetes-prediction-project-new
   ```

2. *(Optional but Recommended)* Create and activate a virtual environment:

   - **Windows**:
     ```bash
     python -m venv venv
     venv\Scripts\activate
     ```
   - **macOS / Linux**:
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```

3. **Install the required dependencies**:

   ```bash
   pip install -r requirements.txt
   ```

---

## Running the Application

Launch the Streamlit dashboard using the following command:

```bash
streamlit run app.py
```

Once executed, Streamlit will open the interactive dashboard in your default browser at:
`http://localhost:8501`
